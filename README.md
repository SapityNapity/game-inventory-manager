# Game Inventory Manager

A small Python project I built while learning programming fundamentals.

The program uses a command-line menu to view player inventories, check for specific items, count unique items, and compare inventories between players.

## What It Does

- Displays all registered players.
- Shows a selected player's inventory.
- Counts the number of unique items in an inventory.
- Checks whether a player owns a specific item.
- Compares two players' inventories to find common and exclusive items.

## Concepts Practiced

- Variables and data types
- Lists and dictionaries
- Nested dictionaries
- Sets and set operations
- `for` and `while` loops
- Conditional statements
- Functions, parameters, and return values
- User input and formatted strings

## Technologies

- Python 3

## What I Learned

This project helped me understand how different Python concepts work together in a single program, particularly how to organize data, create reusable functions, and work with collections.

It also gave me some practice with problem-solving and handling user choices through a menu.
